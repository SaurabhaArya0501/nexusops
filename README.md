# NexusOps

zoneless change detection, hybrid rendering). Built in public as a
31-week architecture deep-dive.

## Status
🚧 Week 1/31 — Foundation: strict TypeScript, tooling, domain models

SSR/hybrid rendering · AI copilot · Full test coverage · Docker + CI/CD

## Stack
Angular 20+ · TypeScript (strict) · ESLint · Prettier
